Free publishing:
1. Sign in/create a free account at https://github.com/
2. Create a PUBLIC repository, e.g. prosteam-ifab.
3. Extract this ZIP and upload index.html plus the complete assets folder.
4. Go to Settings > Pages; select Deploy from a branch, branch main, folder /(root), Save.
5. Use the website URL GitHub provides.

After publishing, submit the URL in Google Search Console: https://search.google.com/search-console/
Google indexing may take time and is not guaranteed immediately.

Before publishing, confirm the listed phone numbers and service descriptions, and add the real business address and official email. The website is not yet live; it must be uploaded to a hosting account.
